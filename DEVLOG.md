## 2026-10-07

- Added `src/invariants.py`: the 1D invariant theory behind antisymmetry -- Vandermonde (log form plus closed-form gradient), elementary symmetric polynomials by the O(n^2) recurrence, power sums and Newton's identities, Weyl-chamber projection with its sign, Schur functions by the bialternant formula, and the Hilbert series of the sign-isotypic module. Feature maps are deliberately smooth and bounded at coalescence; `log(gap)`, `min(gap)` and k-th-root power-sum scaling all let an optimizer manufacture an effective Vandermonde power and break the cusp condition.
- Added `src/symmetry/young.py`: partitions, standard tableaux, hook lengths, Young symmetrizers as group-algebra elements, the S_n character table via Murnaghan-Nakayama on beta-numbers, and Molien series. Neither this repo nor `agca_jax` had any finite-group representation theory; this is the prerequisite for spin-adapted spatial wavefunctions. `molien_sign` and `invariants.antisymmetric_dimensions` compute the same integers by disjoint routes and are tested against each other.
- Added `src/grassmann.py`: Plucker coordinates, the general quadratic Plucker relations (deduplicated to the classical binom(n,4) for Gr(2,n)), the Klein quadric, Pfaffians, and a scale-invariant decomposability residual measuring how far a CI vector is from a single Slater determinant.
- Added `physics/ansatz1d.py`, `physics/vmc.py` and `physics/models1d.py`: a determinant-free 1D ansatz (`alpha log V` + envelope + two-body Jastrow + network on symmetric features) exposing the `physics.nodal` protocol `psi(R) -> (sign, log|psi|)`, so `antisymmetry_error`, `node_distance`, `slice_grid` and `cell_census` all apply to it unchanged; chamber-constrained Metropolis, autodiff local energy, MAD-clipped VMC gradients, and Adam with parameter freezing.
- The Vandermonde exponent is fixed by the cusp condition and frozen, not learned. Corrected from an earlier reading of this: the variational principle is fine -- with equilibrated walkers the true `<E_L>` is minimized exactly at the cusp and equals `E_0` there. What fails is the clipped estimator. Missing the cusp from below leaves a positive `(g - alpha(alpha-1))/r^2` residual whose entire contribution sits in a rare tail (nine percent of walkers above `2 E_0` at `alpha = 1`, `g = 2`), and `Var(E_L)` is infinite for `alpha < 3/2`. MAD clipping removes that tail and with it the penalty, so the clipped objective is minimized at `alpha = 1.90` and the median at `alpha = 1.60`, both below `E_0` (n = 3, lambda = 2). With alpha pinned the tail is gone and clipping stops mattering: 7.50147 clipped versus 7.50107 unclipped. `examples/calogero_vmc.py` reaches E = 14.0009 against the exact 14 for n = 4, lambda = 2, with the variance falling to 6e-3.
- Added `src/agca_bridge.py`: exact-rational Groebner access to the `agca_jax-master` checkout for Vandermonde divisibility and for saturating a polynomial node by the coincidence set to expose spurious nodes. Both repos ship a top-level package named `src`, so `agca_namespace` swaps `sys.modules` and restores afterwards; it is a hack, and the real fix is packaging metadata in one of the two repos.
- Added `tests/test_invariants.py`, `tests/test_young.py`, `tests/test_grassmann.py`, `tests/test_ansatz1d.py`, `tests/test_agca_bridge.py` (164 tests; the agca ones skip when that checkout or its dependencies are missing). Note that `CLAUDE.md` still describes a `jaxqmc/` package with poetry, Hydra and PySCF that no longer exists in this tree.
